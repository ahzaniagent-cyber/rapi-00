# Ekstensi Chrome RAPI · v1.0.0 · by Ahzani Labs
Pasang lewat `chrome://extensions`: aktifkan Developer mode, tekan Load unpacked, lalu pilih folder ini.
- `bridge.js` menerima data FINAL dari halaman RAPI yang bertanda `<meta name="rapi-app">`.
- `ekinerja.js` menampilkan panel di kinerja.bkn.go.id: Salin / Isi, **tanpa menekan Simpan**.
- `config.js` berisi label kolom e-Kinerja. Ubah di sini bila label berubah.
Ekstensi tidak meminta atau menyimpan password maupun cookie.
